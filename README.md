## 项目简介

微信收藏导出是一款 Windows 桌面小工具。选好文件夹和日期，即可把本机已登录微信账号里的收藏导出到本地：图片和视频按发送人分文件夹存放，文本、链接和语音写入清单，多选消息打包收藏会单独生成可离线打开的网页。

安装包和便携版二选一即可使用，不必连接 Agent 或任何云端服务。全程在本机完成，密钥和导出内容不会上传。

## 主要功能

### 📂 短路径导出

- 主界面只有目标文件夹、日期范围和导出
- 默认导出图片、视频，并把文本、链接卡片和语音写入清单（不另存单个文本文件）
- 按发送人分子文件夹；完整件与缩略图放在同一人目录，缩略图文件名带「_缩略」

### 💬 打包收藏出网页

- 在微信里多选消息或图片后收藏的条目，一包一个目录、一份 `index.html`
- 气泡流界面，附件与页面同目录，全部使用相对路径，整个目录可拷走或发给别人
- 入口是 `_导出清单.csv`，不做总索引页
- 包里的图片或视频若当时只有缩略图，到微信里点开或播放后再点「补导」，原件会写回同一目录，网页也会跟着重渲染

### 🔁 未取到原件可补导

- 没在微信里点开过大图、没真正播放过的视频，本地往往只有缩略图
- 完成后会写明原因和建议；点「补导」只处理未取到的条目，写回同一批次
- 新建导出不会复用旧目录，也不会覆盖已有完整件

### 🔊 语音

- 语音会写入导出清单，摘要为「语音 · N 秒」
- 本机能找到音频文件的会导出，页面里可点击播放（同时只播一条）
- 微信 PC 端通常不保留语音本体，这类记为「仅元数据」，不计入「未取到原件」
- 网页语音条为微信风格胶囊：有本体点一下就播，没有则点一下说明原因

### 🔑 本机初始化

- 自动列出本机已登录的微信 4.x 账号（非默认安装位置也可手动指定）
- 从运行中的微信进程提取数据库密钥，普通权限即可，不需要管理员
- 在微信中打开一张收藏图片后，可检测图片密钥；未捕获到时可手动填写

### 🔌 可选 MCP

- 同一套本地能力可通过 MCP 调用：状态检查、预检、导出、补导
- 供其他支持 MCP 的本地工具直接使用，不必经过主界面
- 软件「设置」里可复制配置、写入配置并测试连接

## 操作说明

### 基本使用

1. 安装或解压后打开「微信收藏导出」
2. 首次运行主按钮是「初始化本机环境」：选择微信账号 → 提取数据库密钥 → 在微信里打开一张收藏图片并检测图片密钥
3. 三项就绪后，选目标文件夹，填写起始和结束日期（起止都含当天），点「导出」
4. 完成后可点「打开」进入批次目录；若有未取到原件，按提示在微信里点开大图或真正播放视频，再点「补导」

### 导出结果

每次导出会新建一个带时间戳的批次目录，内含按发送人分好的文件夹，以及：

- `_导出清单.csv`：本批条目一行一条；文本含全文，链接含标题、摘要和网址，语音含时长
- `_导出报告.csv`：文件导出对账
- `_未取到原件.csv`：未取到原件的媒体、原因与建议
- `_导出说明.txt`：给人看的本批说明

打包收藏的网页位于 `<发送人>/聊天记录/<序号>_<收藏日期>/index.html`。

### 命令行（可选）

```bat
微信收藏导出.exe --cli --preflight --from 2026-11-01 --to 2026-11-15
微信收藏导出.exe --cli --export --dest "D:\导出" --from 2026-11-01 --to 2026-11-15
微信收藏导出.exe --cli --retry --batch "D:\导出\export-2026-11-01_2026-11-15-时间戳"
```

## 使用边界

- 只读取本机微信 4.x 的本地数据，不会从微信 CDN 补原件
- 图片需在微信里点开过大图，视频需真正播放过，否则通常只有缩略图
- 微信 PC 端通常不保留语音文件；没有本体的语音只保留时长等元数据，不当作导出失败
- 密钥和导出内容应留在本机，不要随安装包一起发给别人
- 微信换账号、重装或重新登录后密钥会变，回到初始化窗口重新提取即可

## 开发指南

### 环境准备

- Windows
- Python 3.12

### 本地构建

```bash
git clone https://github.com/shaoboqian-arch/wx-export-app.git
cd wx-export-app
python build/build.py
```

版本号唯一真源是 `src/common.py` 里的 `VERSION`。安装包不进 Git，发布走 Releases。

更详细的工程说明、版本记录与复检口径见 [docs/工程说明.md](docs/工程说明.md)。
